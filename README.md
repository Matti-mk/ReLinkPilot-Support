# ReLinkPilot – Support & Feedback

**Offizieller Support für die Browser-Erweiterung ReLinkPilot.**

Willkommen beim Support von ReLinkPilot!

Hier kannst du Fehler melden, Verbesserungsvorschläge einreichen, neue Funktionen vorschlagen oder Fragen zur Erweiterung stellen.

Dieses Repository dient ausschließlich dem Support. Der Quellcode von ReLinkPilot wird hier nicht veröffentlicht.

## 🇩🇪 Deutsch

### 🐛 Fehler melden

Funktioniert etwas nicht wie erwartet?

[**Fehler melden**](https://github.com/Matti-mk/ReLinkPilot-Support/issues/new)

Bitte beschreibe möglichst genau:

- Was funktioniert nicht?
- Was hast du gemacht, bevor der Fehler aufgetreten ist?
- Welche ReLinkPilot-Version verwendest du?
- Welchen Browser und welche Browserversion verwendest du?
- Tritt der Fehler jedes Mal auf?

Screenshots können helfen, das Problem schneller zu verstehen.

### 💡 Verbesserungsvorschläge und neue Funktionen

Du hast eine Idee, wie ReLinkPilot besser werden könnte?

[**Verbesserung vorschlagen**](https://github.com/Matti-mk/ReLinkPilot-Support/issues/new)

Beschreibe deine Idee und erkläre, wie sie dir bei der Nutzung helfen würde.

### 📋 Bekannte Probleme und Bearbeitungsstatus

[**Alle Fehlermeldungen und Vorschläge ansehen**](https://github.com/Matti-mk/ReLinkPilot-Support/issues)

Du kannst bestehende Meldungen lesen, kommentieren und mit einer 👍-Reaktion unterstützen.

### ❓ Fragen und Diskussionen

## 🇬🇧 English

### Welcome to ReLinkPilot Support!

This is the official support and feedback repository for the ReLinkPilot browser extension.

You can report bugs, suggest improvements, request new features, or ask questions.

This repository is intended for support only. The ReLinkPilot source code is not published here.

### 🐛 Report a Bug

Is something not working as expected?

[**Report a Bug**](https://github.com/Matti-mk/ReLinkPilot-Support/issues/new)

Please include the following information:

- What went wrong?
- What steps led to the problem?
- Which ReLinkPilot version are you using?
- Which browser and version are you using?
- Can you reproduce the problem?

Screenshots are welcome.

### 💡 Feature Requests and Improvements

Have an idea to improve ReLinkPilot?

[**Suggest an Improvement**](https://github.com/Matti-mk/ReLinkPilot-Support/issues/new)

Describe your suggestion and explain how it would improve your experience.

### 📋 Known Issues and Status

[**View all Issues and Feature Requests**](https://github.com/Matti-mk/ReLinkPilot-Support/issues)

You can comment on existing reports and support suggestions with a 👍 reaction.

### ❓ Questions and Discussions

[**Open Discussions**](https://github.com/Matti-mk/ReLinkPilot-Support/discussions)

Ask questions and share your thoughts about ReLinkPilot.
